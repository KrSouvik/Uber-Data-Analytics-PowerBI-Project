# 🚖 Uber Data Analysis | Power BI Dashboard

## 📌 Project Overview
An interactive Power BI dashboard built to analyze Uber booking data and generate meaningful business insights related to bookings, revenue, trip distance, vehicle performance and customer ratings.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

## 📊 Dashboard Pages

**1. Home**
- Dashboard landing page with navigation.

**2. Overview**
- Completed and lost bookings.
- Total revenue and trip distance.
- Monthly and quarterly booking trends.
- Vehicle-wise revenue comparison.
- Top pickup and drop locations.
- Customer and driver ratings.
- Booking status analysis.

**3. Vehicle Analysis**
- Vehicle-wise customer count.
- Revenue by vehicle category.
- Completed bookings by vehicle type.
- Vehicle contribution percentage.

## 🎯 Key Objectives
- Analyze booking trends and revenue performance.
- Identify popular pickup and drop locations.
- Compare vehicle-wise performance.
- Understand booking status distribution.
- Monitor key business performance indicators.

## ⚙️ Power BI Features
- Interactive slicers and filters.
- KPI cards.
- DAX measures.
- Interactive charts and tables.
- Dashboard navigation.
